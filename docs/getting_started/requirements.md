# What You’ll Need
This section provides an overview of the materials, tools, and setup steps required to prepare your R15 Wildlife Monitoring Rover for operation.

Before powering on or connecting to the system, ensure that all listed items are available and correctly configured.

## Hardware
|  Required | Description |
|------|-------------|
|  **R15 Rover Unit** | Fully assembled base platform with onboard Raspberry Pi and camera module |
|  **Power Supply** | 12 V DC input or approved Li-ion battery pack (≥ 5000 mAh recommended) |
|  **Laptop / PC** | Linux or Windows 10+, equipped with Wi-Fi and Mobile Hotspot capability |
|  **USB-C Cable** | For direct connection, debugging, or power management during setup |
|  **Gamepad (PS4 Controller)** | For teleoperation via the GUI, recommend PS4 Controller |

|  Optional | Description |
|------|-------------|
|  **Mini HDMI to HDMI Cable** | For first time setup, if using pre-configured RPi |
|  **Monitor** | Require HDMI capability, for first time setup, if using pre-configured RPi |
|  **Micro USB to Multi USB Adaptor** | For first time setup, if using pre-configured RPi. Used for Mouse connection to RPi |
|  **Mouse** | For first time setup, if using pre-configured RPi. Used for RPi |
|  **Keyboard** | For first time setup, if using pre-configured RPi. Used for RPi |
|  **Router or Wi-Fi Hotspot** | 2.4 GHz or 5 GHz band, used to link the rover and control computer increasing operational range |

## Software
|  Required | Description |
|------|-------------|
|  **Operating System** | Raspberry Pi OS (64-bit) pre-installed on the onboard computer |
|  **Python 3.10+ & GStreamer** | Required for video encoding and decoding |
|  **VS Code or IDE** | For code editing and debugging |
|  **Web Browser** | Chrome, Firefox, or Edge for accessing the GUI dashboard |
|  **SSH Client** | Terminal or PuTTY for remote access to the onboard system |
|  **Git** | For cloning and updating the control interface repository |

|  Optinoal | Description |
|------|-------------|
|  **Network Configuration Tools** | Used if configuring static IP or long-range connections |
